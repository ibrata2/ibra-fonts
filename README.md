# IBRA خطوط

طبيب ومحرر الخطوط العربية لـ Windows — **من تصميم و تطوير و تعريب ابراهيم الخزرجي**

## التحميل
آخر إصدار: **[IBRA-Fonts-Setup.exe](https://github.com/ibrata2/ibra-fonts/releases/latest/download/IBRA-Fonts-Setup.exe)**
(إذا طلع تحذير Windows: More info ← Run anyway)

صفحة البرنامج: **https://ibrata2.github.io/ibra-fonts/** — ونسخة تشتغل من المتصفح: **https://ibrata2.github.io/ibra-fonts/app/**

## المميزات
### طبيب الخطوط
- **يفحص خطوط جهازك كلها** (خطوط ويندوز والخطوط المنصبة لك) أو أي ملفات/مجلد ترميه عليه.
- **يصلّح الحروف المنفصلة**: يبني جدول وصل الحروف (بداية، وسط، نهاية) ولام ألف للخطوط القديمة اللي حروفها بمواقع «الأشكال الجاهزة» أو بأسماء أشكال بدون جدول وصل.
- **يحوّل خطوط Type 1 القديمة** (.pfb / .pfa) إلى OpenType — أدوبي وقّف دعمها من فوتوشوب 23 والستريتر 27.3.
- **يرتب الأسماء**: أسماء ماك القديمة، الأسماء المخربطة، اسم PostScript الغلط، وخطين بنفس الاسم يتضاربون بقائمة أدوبي.
- يحوّل **WOFF** ويفصل مجموعات **TTC**.
- **ينصّب المصلّح بضغطة** لحسابك (بدون صلاحية مدير) ويبدّل القديم.
- **يمسح كاش خطوط أدوبي** (`CT Font Cache` و `AdobeFnt*.lst`).
- **ZIP مرتب** حسب عائلة الخط ووياه تقرير.
- زر يمين على أي خط ← **«افحص بـ IBRA خطوط»**.

### محرر الخط
- رسم بقلم قصبة (السماكة حسب الاتجاه والضغط) أو قلم دائري.
- **تتبّع صورة اللوگو** وتحويل الحرف لشكل جاهز.
- أربع أشكال لكل حرف + لام ألف + الأرقام والرموز، ومعاينة مباشرة.
- تصدير **TTF و OTF** فيه وصل الحروف، أو تنصيبه مباشرة.

## البناء
كل دفع (push) لـ `main` يشغّل اختبارات المحرك (HarfBuzz يتأكد إن الحروف تنوصل صح)، ثم يبني البرنامج والمثبّت، يجرّب البرنامج نفسه على ويندوز، وينشر إصدار جديد تلقائياً. وصفحة البرنامج تنتشر على GitHub Pages.

- `web` — المحرك والواجهة (JavaScript) — نفس الملفات تشتغل داخل البرنامج وعلى الويب
- `src/IbraFonts.App` — برنامج Windows (WPF + WebView2): تنصيب الخطوط، قراءة خطوط ويندوز، كاش أدوبي، التحديثات
- `installer` — مثبّت Inno Setup بالعربي
- `site` — صفحة البرنامج
- `tests` — اختبارات المحرك (`npm test`)

يستخدم [opentype.js](https://github.com/opentypejs/opentype.js) (MIT)، [Clipper](https://sourceforge.net/projects/jsclipper/) (Boost)، وخطوط Aref Ruqaa و Readex Pro و IBM Plex Mono (SIL OFL).
